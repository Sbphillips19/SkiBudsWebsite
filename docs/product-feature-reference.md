# Product copy reference

Reviewed **2026-09-26** against the local `../SkiBudsv3` repository. Paths below are relative to that app repository unless stated otherwise. This reference supports the website's product descriptions; it is not a release checklist or a promise of coverage at every mountain.

**Availability:** the website continues to describe SkiBuds as **coming soon to iOS and Android** during the rebuild. Implemented code is evidence of product capability, not verification that a feature or build is available in either app store.

## Weather capabilities

The primary user experience is `app/components/DashboardNavigator/ResortInfoScreen/Component.tsx`. It connects the current-conditions hero, elevation selector, Ski Signal, snow totals, forecast explorer and expandable weather details.

## Boundaries for future copy

- **Elevation:** Open-Meteo and HRRR adapters consume requested elevation; the reviewed NWS and MET Norway adapters do not. `app/services/weather/correction/mapWeatherResultToDisplay.ts` explicitly distinguishes the requested resort elevation from the provider's actual reference elevation. Describe elevation views with source-dependent detail, not universally distinct or independently measured base/summit conditions.
- **Forecast windows:** use “seven local days” when precision matters. The seven-day snow total includes the current resort-local calendar day, rather than promising a rolling 168-hour accumulation. Interval timing ranges are not probabilistic confidence intervals.
- **Radar:** describe recent imagery, not a nowcast, automatic storm tracking or an arrival-time prediction.
- **Alerts:** describe opt-in checks on forecast refresh and return to the app. Do not promise always-on background monitoring, server push while the app stays closed or that a rider will never miss a storm. Notification permission and forecast coverage matter.
- **Sources:** defaults in `app/services/weather/sources/registry.ts` are NWS, WeatherAPI and MET Norway. Coverage, credentials and environment settings affect availability. The main forecast uses a primary source with fallback; do not promise a fixed source/model count or universal ensemble blending.
- **Confidence and AI:** confidence reflects available source agreement; it is not a calibrated snowfall probability or proof of forecast accuracy. Optional diagnostics, correction code and research scripts do not establish always-on AI, validated self-learning or superiority to other weather products.
- **Weather and safety:** `DayPlannerContent.tsx` explicitly describes weather-only scores. `OfficialAvalancheCard.tsx` separately displays applicable official zone information and links to the full bulletin. No weather score establishes avalanche safety, open terrain or operational lifts; wind-hold estimates are not confirmed resort status.
- **Offline maps:** promise only supported downloaded base maps. Do not extend offline coverage to all resorts, every terrain/trail overlay, weather, lift status or live friend locations.
- **Code versus product UI:** an isolated calculation, preference or research script does not prove a shipped user-facing feature. Goggle-lens recommendations, a dedicated clearing window and favorite-resort comparison were not verified in the active UI.
